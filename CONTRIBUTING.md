# Contributing

We welcome focused fixes, visual improvements, new route conventions, and test fixtures. Open an issue explaining the limitation before substantial changes.

1. Use Node.js 20 or later.
2. Run `npm install --ignore-scripts` then `npm run check`.
3. Include tests for scanner changes and account for false positives.
4. Never add real tokens, keys, production credentials, or sample user data.
5. Preserve local-first operation and explicit scope: this is not a full security scanner.

Please be respectful, accurate, and specific in review discussions.
