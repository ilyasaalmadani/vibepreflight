# Security policy

**Do not report vulnerabilities in scanned applications as VibePreflight vulnerabilities.** VibePreflight supplies heuristic inventory only.

For a vulnerability in VibePreflight itself, please use GitHub's **Report a vulnerability** private advisory flow rather than opening a public issue. Do not post exploits or sensitive content publicly.

The tool does not execute project code, upload files, or follow symlinks. Outputs may nonetheless contain filenames, paths, or names of environment variables. Treat generated reports as project metadata and avoid publishing reports containing sensitive project structure.
