# Five-minute demo

1. Show a small Next.js prototype with routes and environment variable references.
2. Run `npm run check`.
3. Run `node dist/cli.js examples/unsafe-next --html demo.html`.
4. Open the offline graph and filter by routes, env, deployment, and framework.
5. Explain one warning as a review prompt, not confirmed exploitability.
6. End by comparing JSON and CI exit codes.

Positioning: visualization and understanding before deployment, **not a security audit**.
